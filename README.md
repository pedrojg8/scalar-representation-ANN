# Scalar Representations of Neural Network Training Dynamics
Repository for the paper "Scalar Representations of Neural Network Training Dynamics" (2026), Pedro Jiménez-González, Miguel C. Soriano and Lucas Lacasa, https://arxiv.org/abs/2606.30384

This repository provides a baseline implementation of the scalar embedding methodology introduced in the paper. The included MNIST example generates perturbed neural-network training trajectories, constructs their corresponding scalar embeddings, and computes the main observables analyzed in the study, including embedding-based decorrelation times, asymptotic embedded states, and nearest-neighbor spacings.

Post-processing steps such as Lyapunov exponent fitting, extended statistical analysis, and final figure generation are not included in this repository. Other architectures, datasets, and hyperparameter configurations can be implemented within the same framework by modifying the model definition, data source, and training settings. Although the example provided focuses on scalar embeddings, the methodology can be readily extended to higher-dimensional embeddings, including two- and three-dimensional representations.
